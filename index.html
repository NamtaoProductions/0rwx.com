0rwx

A simple model of AI usage, inspired by unix permissions.

INTRODUCTION

We need new language to talk about large language models. 0rwx is my attempt.

A labelling system is vital for domain experts to talk about AI in a clear way. The difference between the 4 levels is not necessarily about what TOOL you use, but your ability to scrutinise the generated work.

I have employed this simple framework to discuss my and others' work with less judgement and confusion, and I hope the 0rwx framework makes it just a little easier for you too. They are:


    ZER0

    AI can't read or write to your work

    HAND MADE
    I read the docs
    painting w/paint
    playing music
    "I think"

    READ

    AI has read-only permissions

    AI INSPIRED
    I write the code
    reference images
    chord inspiration
    "I make"

    WRITE

    AI has read-write permissions

    AI COLLABORATION
    I read the code
    generated collages
    loop generation
    "I fix"

    EXECUTE

    YOU can no longer read your work

    AI MADE
    I vibe code
    image generation
    song generation
    "I curate"
